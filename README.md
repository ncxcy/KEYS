# OTAID & TV Firmware Keys

A curated collection of **OTAIDs, firmware encryption keys, and platform-specific cryptographic constants** identified across smart-TV firmware ecosystems.

The collection covers multiple television manufacturers, SoC families, firmware generations, and software platforms, including **LG webOS, LX/LGE, MStar, MediaTek, Realtek, Broadcom, Hisense, Vestel, KTC**, and related platforms

## Overview

This repository documents OTA identifiers and cryptographic material associated with TV firmware and update systems

The dataset is organized around:

- Manufacturer
- SoC / chipset family
- Platform generation
- Firmware generation
- webOS version
- Internal platform identifier
- Firmware family
- Known cryptographic usage

The purpose of this project is firmware reverse engineering

## OTAIDs

OTAIDs are identifiers used within firmware and over-the-air update ecosystems to associate software with specific platforms, devices, or firmware families
